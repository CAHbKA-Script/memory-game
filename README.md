# memory-game

Работа выполнена в ходе прохождения курса rsschool.
---
### Об игре
- суть игры заключается в нахождении 8 пар карточек с одинаковыми картинками
- одновременно можно посмотреть только две карточки, в случае их совпада, карточки оставются открытыми
- игра продолжается до тех пор, пока не будут найдены все пары
---
### Запуск
- открыть игру можно после перетаскивания файла index.html в браузер, предварительно загрузив все файлы с github
- либо открыть без установки по [ссылке](https://cahbka-script.github.io/memory-game/)
